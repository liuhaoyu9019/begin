# 智能房贷计算器网站

一个现代化、响应式的房贷计算器网站，仿照 https://fangdai.fktool.com/ 的设计和功能，但采用了更现代的技术栈和UI设计。

## 🌟 功能特点

### 🎨 现代化设计
- **响应式布局**：完美适配电脑、平板、手机
- **Material Design风格**：现代化的UI组件和动画效果
- **渐变色和阴影**：提升视觉层次感
- **图标字体**：使用Font Awesome图标

### 🧮 计算功能
- **三种贷款类型**：商业贷款、公积金贷款、组合贷款
- **两种还款方式**：等额本息、等额本金
- **实时计算**：输入变化时即时更新结果
- **详细还款计划**：展示前12期还款明细
- **利率折扣**：支持多种利率折扣设置

### 📱 用户体验
- **标签页切换**：流畅的标签页切换动画
- **表单验证**：实时输入验证和错误提示
- **平滑滚动**：页面内导航平滑滚动
- **移动端优化**：触摸友好的交互设计

## 📊 计算算法

### 等额本息计算公式
```
月利率 = 年利率 / 12
月供 = 贷款金额 × 月利率 × (1 + 月利率)^贷款期数 ÷ [(1 + 月利率)^贷款期数 - 1]
总利息 = 月供 × 贷款期数 - 贷款金额
```

### 等额本金计算公式
```
每月本金 = 贷款金额 ÷ 贷款期数
第n期月供 = 每月本金 + (贷款金额 - 每月本金 × (n-1)) × 月利率
总利息 = ∑(每期利息)
```

## 🔧 自定义配置

### 修改端口
编辑 `server.js` 文件，修改 `PORT` 常量：
```javascript
const PORT = 3000; // 改为其他端口
```

### 添加新功能
1. **添加新的计算类型**：在 `calculator.js` 中添加新的计算逻辑
2. **修改样式**：编辑 `css/style.css` 文件
3. **添加页面**：创建新的HTML文件并在服务器中配置路由
